## Selected Work

### [custom-auth](https://github.com/DevCodeHub99/custom-auth)
Framework-agnostic, production-oriented authentication SDK for modern apps.

- Modular monorepo architecture
- Session management, RBAC, OAuth, MFA, OTP, passwordless login
- Prisma, Drizzle, and Mongoose integration support
- Built for developer ergonomics and production reliability

### [event-overlay](https://github.com/DevCodeHub99/event-overlay)
Open-source visual utility package published on npm.

- Lightweight canvas-based overlay library
- Simple integration for creative web effects
- Published and maintained as a usable developer package

### [Invoice Desk](https://github.com/DevCodeHub99/sndt-invoice-desk)
Business software platform for invoice and operational workflows.

- GST-aware invoice processing and business logic
- PDF generation and operational dashboards
- Designed for practical business value and product usability

### [VisionVoice](https://github.com/DevCodeHub99/VisionVoice-Multilingual-Visual-Aid-for-the-Visually-Impaired)
AI-assisted accessibility-focused product.

- Real-time visual-to-audio assistance
- Multilingual interaction design
- Applied AI for accessibility and utility

### [Quick Tools](https://github.com/DevCodeHub99/quick-tools)
Developer productivity web app with utility workflows.

- Local-first developer tools
- Conversion, validation, generation, and utility flows
- Focused on shipping real day-to-day value
