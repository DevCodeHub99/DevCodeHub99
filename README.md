## 📚 Technical Deep Dives

#### 🔐 [custom-auth](https://github.com/DevCodeHub99/custom-auth)
> Production-grade, framework-agnostic authentication SDK for Node.js, edge runtimes, and browser-based apps.

* Modular monorepo architecture with core, React, and Next.js packages
* Secure auth primitives including session management, RBAC, MFA, OAuth, OTP, and passwordless flows
* Designed for developer ergonomics and real-world application needs
* Supports Prisma, Drizzle, and Mongoose adapters

---

#### 📄 [Invoice Desk](https://github.com/DevCodeHub99/sndt-invoice-desk)
> GST-compliant invoice and business management platform for Indian organizations.

* Built for real-world invoicing workflows and tax calculations
* PDF generation, product management, and operational dashboards
* Focused on practical business utility and smooth UX

---

#### 📦 [event-overlay](https://github.com/DevCodeHub99/event-overlay)
> A lightweight creative overlay library to add festive, animated, and aesthetic visual effects to websites.

* Canvas-based rendering with zero heavy dependencies
* Fast integration with simple usage patterns
* Great example of shipping a useful utility package from idea to npm publication

---

#### 👁️ [VisionVoice](https://github.com/DevCodeHub99/VisionVoice-Multilingual-Visual-Aid-for-the-Visually-Impaired)
> Multilingual AI-powered visual assistance for accessibility-focused use cases.

* Real-time description of visual content
* Built for practical accessibility impact
* Combines AI, camera input, and speech synthesis for meaningful product value

#### 🛠️ [Quick Tools](https://github.com/DevCodeHub99/quick-tools)
