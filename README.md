## 👨‍💻 About Me

> *"Designer by eye, developer by code. I like building web applications, solving practical problems, and writing clean, reliable code."*

Full-stack developer from India 🇮🇳 building web applications, developer utilities, and side projects. I enjoy working across the whole stack - from crafting clean UI designs to writing backend APIs and working with databases.

- 🛠️ **Development:** Building web apps with **TypeScript, React, Next.js, Node.js, PostgreSQL, and MongoDB**.
- 📦 **NPM Packages:** Published packages including [`@custom-auth`](https://www.npmjs.com/org/custom-auth) (modular auth SDK) and [`@event-overlay`](https://www.npmjs.com/org/event-overlay) (canvas overlay utilities).
- 🤖 **Accessibility & AI:** Built *VisionVoice*, an accessibility tool using the Google Gemini API to translate visual input into spoken audio.
- ✍️ **Writing:** I write technical guides, cheat sheets, and project walkthroughs on [dev.to/devcodehub99](https://dev.to/devcodehub99).

## 🚀 Projects

### [VisionVoice — Visual Aid for the Visually Impaired](https://github.com/DevCodeHub99/VisionVoice-Multilingual-Visual-Aid-for-the-Visually-Impaired)
*An accessibility tool that translates images and camera input into spoken descriptions.*
- Uses Google Gemini API and OpenRouter for image description and OCR text reading
- Bring-Your-Own-Key (BYOK) model with client-side key storage
- Speaks descriptions aloud in multiple languages using the Web Speech API
- `Next.js` • `TypeScript` • `Google Gemini API` • `TailwindCSS`

### [SNDT Invoice Desk](https://github.com/DevCodeHub99/sndt-invoice-desk)
*A GST-compliant billing and invoice management web app for small businesses.*
- Automated tax calculations for CGST, SGST, and IGST
- Dynamic UPI QR codes for payment collection and client-side PDF invoice generation
- User authentication and invoice management with Next.js, MongoDB, and Zustand
- 📖 [Read the project walkthrough on DEV.to](https://dev.to/devcodehub99)
- `Next.js` • `TypeScript` • `MongoDB` • `Zustand` • `TailwindCSS`

### [Quick Tools](https://github.com/DevCodeHub99/quick-tools)
*An offline-capable developer utility suite and PWA for everyday developer tasks.*
- Includes UUID generator, JSON formatter, hash/password tools, regex tester, and calculators
- Built as a submission for the GitHub Copilot CLI challenge on DEV.to
- Tested with Vitest and designed for local, private in-browser use
- 📖 [Read the Copilot CLI write-up on DEV.to](https://dev.to/devcodehub99)
- `Next.js` • `TypeScript` • `Vitest` • `PWA`
