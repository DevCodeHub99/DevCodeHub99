### 📂 Technical Breakdown & Architectures

#### 🔐 [custom-auth](https://github.com/DevCodeHub99/custom-auth)
> **Production-grade, framework-agnostic modular authentication SDK for Node.js, Edge runtimes, and Browsers.**

*   **Modular Monorepo Architecture**:
    *   `@custom-auth/core` — Core auth engine handling session lifecycles, TOTP/MFA gates, JWT signing, RBAC rules, and OAuth configurations.
    *   `@custom-auth/react` — Frontend React context and custom hooks (`useSession`, `useSignIn`, `useSignUp`, `usePasskeys`, `useMfa`, `useMagicLink`).
    *   `@custom-auth/nextjs` — Server helpers and Edge-compatible middleware (`getServerSession`, `requireSession`, `withRole`, `withAuth` middleware protection).
    *   **DB Adapters**: Plug-and-play adapters for **Drizzle ORM**, **Prisma**, and **Mongoose (MongoDB)**.
    *   **Email Adapters**: Out-of-the-box support for **SMTP (Nodemailer)** and **Resend API** (fetch-based, edge-compatible).
*   **Enterprise-Grade Features**:
    *   **Passwordless**: WebAuthn/Passkeys (biometric/hardware key verification), Magic Links, and 6-digit Email OTP codes.
    *   **OAuth Integration**: Google and GitHub OAuth with secure CSRF state validation, timing-safe checks, and auto user-matching.
    *   **TOTP Two-Factor (MFA)**: QR Code generation, setup/enable/disable flow, and built-in verify route with rate-limiting (5 attempts/min).
    *   **RBAC & Sessions**: Secure cookies with automatic HTTPS detection, sliding sessions, global revocation, and role checks (`admin`, `user`).
*   **Tech Stack**: TypeScript, Node.js, Web APIs (`Request` / `Response`), Jose, Speakeasy, WebAuthn.
*   **Links**: [GitHub Repository](https://github.com/DevCodeHub99/custom-auth) · [NPM Core Package](https://www.npmjs.com/package/@custom-auth/core)

<details>
<summary>🔧 How to enable the snake animation</summary>
<br>

Create `.github/workflows/snake.yml` in this repo:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Then go to **Actions → Generate Snake → Run workflow** to trigger it once.
